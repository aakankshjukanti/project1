### Effects library (names you can use)
| Name | What it looks like |
|---|---|
| Text behind me | Big headline sits behind your head (works from normal footage) |
| Card swap | You shrink into a rounded card, turn into another clip mid-shrink, a row of cards slides in and drifts |
| Colour flip | Hard cuts to solid accent / ink screens on each phrase; a word rolls into the next and the colours swap |
| Counter race | A number races up from 0 and lands on a value (e.g. 1,000,000+) |
| Zoom-through cut | A jump cut hidden by a quick push-in that eases back — used on every cut by default |
| Gradient CTA | Dark gradient rises from the bottom, small label + big word typed on the VO, then ticked pointers |
| Browser mockup | Screenshots inside a clean browser window that pans and zooms to the detail |
| Pointer click | An arrow glides to a spot and clicks, with a ripple |
| Rolling number | Digits roll from one value to another (e.g. $26.50 → $48.94) |
| Highlight marker | Accent marker wipes behind a key phrase |
| Side card | You move into a card beside the graphics (16:9) or below them (9:16) |
| Headline to pill | A big headline shrinks into a small corner tag that stays on screen |
| Word-by-word captions | On by default (looks: clean, block, highlight, pop) |
| Whip pan | Fast blurred pan between two unrelated shots |
| Push | The next scene pushes the last one out |
| Mask wipe | A soft-edged wipe reveals the next scene |
| Match cut | Cut hidden inside a shared shape or movement |
| Dip | Quick dip through the background colour |
| Speed ramp | Glide into slow-mo (or speed-up) and back out |
| Beat cut | Cuts land on the beat of your music |
| Tighten it | Silence and filler words removed, every join hidden as a punch-in |
| Cut to the music | Whole edit built off the track: slow intro, faster build, hardest on the drop |
| Film look | Grain, halation, light leak, gate weave (looks: clean, film, super8, cinema) |
| Sound pass | Whooshes, impacts and risers placed off the cut list, ducked under the voice |
| Morph into state | An element becomes its next state in place — the row you click turns into the confirmation, instead of one thing fading out and another in |
| Directional blur | Anything moving fast smears and only resolves as it slows, including rolling digits and redrawing lines |
| Overshoot and settle | Arrivals come in slightly too big, or just past the mark, and ease back |
| Live data morph | A chart or list updates in place: only the data moves, the panel never re-enters |
| Ghosted type-ahead | Text types itself into a pill that grows with it, the words still to come already there in pale grey |
