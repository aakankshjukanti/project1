# partners-intro

Drop this video's files here. Nothing in this folder is used by any other video.

1. Fill in `BRIEF.md` (the script goes in it too).
2. Put files in the folders below.
3. Run `npm run prep -- partners-intro`, then start the session with "start partners-intro".

| Folder | Put here |
|---|---|
| `footage/` | Your talking-head clip, straight off the phone (any name). For text behind you, also its green-screen copy named `<same name>-GS.mp4`. B-roll clips. |
| `screenshots/` | Screenshots to show (PNG/WebP). List what must be blurred in the brief. |
| `audio/` | Your sound-effects library for this video, if any. |
| `processed/`, `cutouts/` | Generated — leave empty. |
